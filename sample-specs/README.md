### Production Specs and Image Building Moved

To reduce the incidence of multi-developer conflicts during simultaneous spec and nb-wrangler tool development, spec and image development have both moved to [spacetelescope/nb-wrangler-images](https://github.com/spacetelescope/nb-wrangler-images) on GitHub.

The residual specs under this directory are here for testing the nb-wrangler tools themselves and for historical reference for devs that worked on them here.  Any content new work, including image pipelines and automated builds as well as specs, should be performed on [spacetelescope/nb-wrangler-images](https://github.com/spacetelescope/nb-wrangler-images).
