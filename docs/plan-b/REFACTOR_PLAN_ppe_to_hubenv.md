# Refactoring Plan: Rename `ppe` Tool → `hubenv`

**Goal:** Rename the `ppe` CLI tool to `hubenv` across all package code, tests, and docs.

## Summary of Scope

| Area | Files | Key Changes |
|------|-------|-------------|
| Package code (`nb_wrangler/ppe/`) | 23 `.py` files | Module dir, class names, func names, CLI prog, file extensions, docstrings |
| Entry point | `pyproject.toml` | `ppe = ...` → `hubenv = ...` |
| Tests (`tests/ppe/`) | 14 test files | All imports, patches, assertions, test helper names |
| Docs (`docs/plan-b/`) | 19 markdown files (2 top-level + 18 phases) | Tool name references, phase filenames, CLI examples |

---

### 1.7 Completions script content (`completions.py`)

The `completions.py` module generates shell completion scripts as strings. All `ppe` references in those generated strings must become `hubenv`:

- `complete -c ppe` → `complete -c hubenv` (fish)
- `#compdef ppe` → `#compdef hubenv` (zsh)
- `complete -F pep_completion_function ppe` → `complete -F hubenv_completion_function hubenv` (bash)
- `_ppe()` → `_hubenv()` (zsh function name)
- `# bash completion for ppe` → `# bash completion for hubenv`
- `# Generated by nb_wrangler.ppe.completions` → `# Generated by nb_wrangler.hubenv.completions`
- `eval "$(ppe completions bash)"` → `eval "$(hubenv completions bash)"`
- `ppe completions bash > ...` → `hubenv completions bash > ...`
- `~/.config/fish/completions/ppe.fish` → `~/.config/fish/completions/hubenv.fish`
- `${fpath[1]}/_ppe` → `${fpath[1]}/_hubenv`
